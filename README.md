# OA BattleRoyale

Minecraft Java Edition 26.3向け、最大10人のバトルロワイヤル用データパックです。

## ダウンロード（v1.9.9）

- [データパック](downloads/OA_BattleRoyale_v1.9.9.zip)
- [リソースパック](downloads/OA_BattleRoyale_Resources_v1.9.9.zip)

各ファイルのページから「Download raw file」でダウンロードできます。
データパックはワールドの `datapacks`、リソースパックは各プレイヤーの `resourcepacks` にZIPのまま配置してください。両方ともv1.9.9を使用します。

ZIP内の `README_JA.md` に操作方法が含まれています。初回はOPが `/function oa:admin` を実行します。

マップやロビーの生成は対象範囲を上書きするため、ワールドをバックアップしてください。

配布ZIPは元のv1.9.9と同一です。ゲーム内の動作検証は実施していません。
